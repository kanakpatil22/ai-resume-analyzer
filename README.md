# 🧠 AI Resume Analyzer

An intelligent, full-featured Python web application that analyzes resumes (PDF or DOCX), matches skills across multiple domains, checks resume quality, compares against job descriptions, and provides actionable improvement suggestions — all through a clean, live-deployed web interface.

## 🌐 Live Demo

👉 **[Try it here](https://ai-resume-analyzer-nmd9sqkbu56afnxeg9tr4r.streamlit.app/)**

No installation needed — just open the link, upload a resume (or try the built-in sample), and get instant results.

## 🚀 Features

- 📄 **PDF & DOCX Support** — extracts text from both formats
- 🎯 **Multi-Domain Skill Matching** — covers CS/IT, Engineering, Commerce, Management, Law, Design, Healthcare, and more
- 📊 **Resume Score** — percentage-based skill match score with visual progress bar
- 📋 **Resume Quality Check** — flags missing elements like internships, certifications, projects
- 📏 **Resume Length Check** — flags resumes that are too short or too long
- 🎯 **Job Description Comparison** — paste any job posting to see a tailored match score
- 📚 **Skill Learning Suggestions** — direct links to learn missing skills
- 📥 **Downloadable Report** — get your analysis as a text file
- 🎨 **Custom UI** — themed interface with sidebar guide and instant feedback
- 🧪 **Try Instantly** — built-in sample resume, no upload required to test

## 🛠️ Tech Stack

- **Python 3**
- [Streamlit](https://streamlit.io/) — web interface
- [pdfplumber](https://pypi.org/project/pdfplumber/) — PDF text extraction
- [python-docx](https://pypi.org/project/python-docx/) — DOCX text extraction
